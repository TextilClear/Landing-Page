TEXTILCLEAR - LANDING PAGE
1. Descomprime el ZIP.
2. Abre index.html en tu navegador.
3. Los archivos index.html, styles.css y script.js deben permanecer en la misma carpeta.

La página es adaptable a móviles. El formulario muestra una confirmación local, pero para enviar mensajes reales necesitas conectarlo a un backend o servicio de formularios.
Los botones Ingresar y Regístrate gratis son enlaces de demostración que llevan a Contacto; conecta tus pantallas de autenticación para habilitarlos.
